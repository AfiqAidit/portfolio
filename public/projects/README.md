# Project screenshots

Drop PNG or WebP files here, then set `image` in `src/content/featured-work.ts`.

Suggested filenames:

- `selangkah-plus.png` — app screen or architecture (no secrets)
- `scms.png` — dashboard or prescription sticker (redact patient data)
- `sdms.png` — dental chart or appointment UI (redact data)
- `gis.png` — map view (Putrajaya/Labuan safe layers only)

Keep files under ~500 KB each (compress with Squoosh or similar).
