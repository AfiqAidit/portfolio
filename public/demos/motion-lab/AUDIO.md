# Motion lab ambient audio

The demo plays only `ambient.mp3` (no synth bed). Sound starts on when the page opens. If the browser blocks autoplay, the first click or tap starts the same loop.

## Track in use

- Title: The Lonely Wind
- Artist: Leberch
- Length: about 1:52
- Source: [Pixabay Music](https://pixabay.com/music/search/the%20lonely%20wind/) (download id 241868)
- License: Pixabay Content License (free to use, including commercial, no attribution required; credit is still listed here)

`audio.loop` is on, and if the file ever ends the player starts it again. Mute fades out and pauses. Unmute continues the same loop.
